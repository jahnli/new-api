# 概览页订阅额度面板优化

**日期**: 2026-09-24

## 涉及文件

- `web/src/features/dashboard/components/overview/summary-cards.tsx` — 保留完整订阅记录并将当前订阅展示交给独立概览组件，使高级模型额度数据能够进入概览面板。
- `web/src/features/dashboard/components/overview/subscription-summary.tsx` — 展示套餐总额度，并在高级额度策略启用时增加标准模型与高级模型的已用额度、额度上限、占比和分阶段进度；无限额度、外部模式或未启用高级额度时保持单总额度布局。

## 变更说明

- 总额度继续作为主要信息展示，标准模型与高级模型额度使用无边框的紧凑摘要行展示，移除重复图标、卡片边框和可见使用百分比以压缩面板高度，并复用项目 `Badge` 和 `Progress` 组件。
- 启用分类额度时，标题、总额度、分类额度与重置时间在面板可用高度内均匀分布，并适当增加两类额度之间的间距，减少上下空白集中在面板边缘的观感。
- 总额度和分类额度均按 50%／80% 阈值使用绿、橙、红三档状态色，高级模型额外展示当前分配占比。
- 额度数字沿用订阅模块的精确格式化能力，百分比使用当前界面语言对应的数字格式。
- 下一次重置时间保留在面板底部；本次仅调整概览页订阅面板，不修改钱包页订阅列表和后端额度逻辑。

## 自 CHANGELOG 说明列迁入

概览页汇总卡片右侧面板改为订阅详情：展示当前订阅用量与总额、用量进度条（按百分比变色）、下次重置时间，无订阅时显示空状态；移除余额健康状态与续航天数；订阅计划名称以标签形式展示在标题右侧。
