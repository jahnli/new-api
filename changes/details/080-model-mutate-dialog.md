# 模型管理操作统一改为居中弹框

**日期**: 2026-09-19

## 涉及文件

- `web/src/features/models/components/drawers/model-mutate-drawer.tsx` — 复用模型表单并支持弹框与抽屉两种呈现方式
- `web/src/features/models/components/models-dialogs.tsx` — 将模型新增、补充资料、编辑与定价入口统一切换为弹框

## 变更说明

- 模型管理页的新增、补充资料、编辑和定价操作统一使用居中弹框，弹框宽度为视口的 60%
- 保留原有元数据、定价及渠道与分组三个区域，以及保存、错误提示和未保存关闭确认行为
- 每次打开操作时按当前模型和初始区域重新挂载表单，避免沿用上一次操作的临时状态
- 供应商关联模型中的独立入口继续使用默认抽屉呈现，不受模型管理页调整影响
