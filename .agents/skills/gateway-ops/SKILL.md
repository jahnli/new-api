# 网关运营助手

把用户的运营需求映射到已有脚本，补全时间与对象参数，运行后交付报告或文件。复用仓库脚本，不另建运行器，不复制统计和定价算法；通过维护模式让技能随脚本演进。

## 先区分维护与业务运行

- “更新脚本清单”“把新脚本接入技能”“同步 scripts 的变化到技能”属于维护模式，先读 [脚本接入与更新](references/maintenance.md)。仅扫描、核对源码和更新技能文件，不运行运营脚本、不连接业务服务、不安装业务依赖。
- “检查技能是否需要更新”只报告差异，不写文件；“更新技能/清单”授权维护技能文件，不授权执行同步、发消息等业务动作。“同步模型价格”“更新报价表”属于业务运行，不因含有“更新/同步”而误判为维护。
- “列出支持的操作”时先用 `rg --files scripts` 核对现有清单；展示已接入能力，另列未接入候选及已失效入口。不因发现新文件就执行或自动修改技能。
- 正常业务调用按下文运行。若源码核对发现参数或行为已变，先修正本次指令理解，不能用旧参数运行；明显的文档偏差可随本次调用兼容更新，新增写入/发送或覆盖范围扩大时按实际授权处理。

## 指令入口

支持 `$gateway-ops` 和自然语言请求。单独调用或要求“列出支持的操作”时展示下表及示例，不连接数据库或 API。

| 请求 | 脚本 | 详细规则 |
| --- | --- | --- |
| 本周、上周、指定时间段的用量报告 | `scripts/weekly_stats.py` | [报表](references/reports.md) |
| 公司月报 | `scripts/company_stats.py` | [报表](references/reports.md) |
| 一级部门月报 | `scripts/primary_department_stats.py` | [报表](references/reports.md) |
| 二级部门月报 | `scripts/secondary_department_stats.py` | [报表](references/reports.md) |
| 个人月报 | `scripts/personal_monthly_stats.py` | [报表](references/reports.md) |
| 导出新的模型价格 Excel | `scripts/model_square_prices.py` | [价格](references/prices.md) |
| 更新已有报价表 | `scripts/sync_price_sheet.py` | [价格](references/prices.md) |
| A 站基础定价和模型广场推荐同步到 B 站 | `scripts/sync_model_prices.py` | [价格](references/prices.md) |

只读取当前操作对应的参考文件。`scripts/official_model_prices.json` 是价格参考数据，不是可执行脚本。新增文件需按维护规则核实后才接入；用户明确要求运行未接入脚本时，先完成该脚本的接入，再按本次运行请求执行，不顺带执行其他新增脚本。

## 运行流程

1. 从当前工作区向上定位含 `scripts/` 和 `go.mod` 的项目根目录，读取适用的 `AGENTS.md`，在根目录运行命令。路径不固定为某台机器的盘符。
2. 明确操作、统计对象、时间范围、目标文件/站点，以及是否预览、写入或发送。复用本次对话已提供的信息；只询问无法推断且影响结果的缺项。部门层级不明确时询问一级还是二级，不凭名称猜测。
3. 以当前北京时间解析“上个月”“今年”等时间。月报始终显式传 `--year`，不依赖脚本固定的默认年份。仅给月份时用当前年份并说明；整月统计和截至当前的统计不能混为一谈。
4. 阅读所选脚本的参数解析、配置加载和主入口，核对参考文件是否仍准确。只通过读源码核查，不通过导入运营模块检查配置；不要输出内置凭据或 `.env` 全文。
5. 检查 Python 3.10+、所需依赖、配置是否存在、输入文件及输出目录。优先使用已有项目 Python 环境；Windows 的 `python` 可能只是商店占位程序，要核实解释器可用。没有项目解释器时可通过可用的工作区依赖工具定位内置 Python，不把本机缓存路径写死在命令模板中。依赖检查用 `importlib.util.find_spec`，不用运行运营脚本充当检查。缺包时可安装到项目已有或新建的 `.venv`，只装本次需要的包，不改系统或内置 Python。只要求“检查条件”时列出缺项，不安装、不联网、不执行脚本。
6. 运行前简短说明具体范围和操作；把参数作为独立参数传递，PowerShell 使用调用运算符和参数数组，不把用户名、部门名或路径拼接成待执行代码。凭据留在环境变量或进程内存中，不放入命令文本、报告或技能文件。捕获输出并在展示前去除可能包含的凭据。
7. 检查退出码、脚本的业务成功/失败信息和实际产物。成功退出但报告为空、文件缺失或结果不完整时如实说明。先核对文件是否属于本次运行，不能把上次残留的图片当作本次结果。

## 执行边界

- 用户只要求说明、列操作、检查或“先别运行”时，不执行运营脚本。要求“只给命令”时生成脱敏命令，不执行。
- “预览价格变化”允许运行脚本的只读预览，会连接对应数据库或 API；与不联网的“只检查运行条件”区分。两个同步脚本均不带 `--apply` 时预览。
- 询问“能同步什么”“看看差异”不授权写入。明确要求更新/执行同步时，先预览并说明实际文件或同步方向和覆盖范围，再按已授权范围执行 `--apply`，不重复索要相同授权。预览发现范围与请求不一致时，暂停相关写入并澄清。
- 仅在用户明确要求发送飞书时使用 `--send-feishu`；生成报告不隐含发送。发送失败或部分成功时先确认已送达内容，不自动重发整批消息。不得改用其他接收人或机器人。
- 跨站写入或发送结果不明时，停止后续写入/发送，核对当前状态后报告；不盲目重试、不自动回滚，不把一次授权扩展为循环操作。
- 本技能执行现有脚本，不为满足不支持的站点、分组、日期参数而临时修改代码或 monkey-patch。需要扩展时说明具体缺口，按用户另行授权的代码任务处理。涉及计费改动或审查前完整读取 `.agents/rules/billing.md`；价格同步操作也先读取该规则，保留脚本的计价校验。
- 不把运营调用扩展为自动升级依赖、更新官网价格、部署、推送代码或设置定时任务。现有部署技能继续负责部署。

## 组合任务与交付

- 支持对用户列出的多个公司、部门、用户或月份逐项运行，使用相同的明确时间口径并汇总。普通批量报表可继续处理其他独立项目，但必须列明失败项；写入/发送出现不确定结果时停止后续副作用。
- 对比表保留人数、Token、费用、缓存命中率等脚本实际给出的字段和单位，不重算历史账单。公司与部门可能重叠，不能直接相加；不同筛选口径不可宣称可直接对账。保留历史快照缺失、回退分摊等提示。
- 无 `--output` 的月报默认直接返回文本；用户要求保存时将已脱敏输出保存为 UTF-8 文本。文件默认放入用户指定目录，未指定时可用项目 `output/gateway-ops/<北京时间运行时间>/`，避免覆盖已有文件，不自动提交产物。
- 返回操作、对象/时间范围、简明结果及实际生成文件的绝对路径链接。图片在有助于阅读时直接展示；不声称存在脚本没有生成的 Excel 或 PDF。
- 更新操作报告变更摘要、实际备份路径和写入结果；“无变化”与“已写入”区分。跨站同步还要区分数据库写入成功和应用缓存已刷新。

示例：

```text
$gateway-ops 列出支持的操作
$gateway-ops 检查 scripts 中有哪些脚本尚未接入技能，只报告差异
$gateway-ops 更新脚本清单，将新增、变更和删除同步到技能，不运行脚本
$gateway-ops 将 scripts/新脚本.py 接入技能，补齐参数说明和中文指令示例，不运行
$gateway-ops 生成上周用量报告
$gateway-ops 生成上周完整自然周报告并发送飞书
$gateway-ops 统计某公司 2026 年 9 月用量
$gateway-ops 对比一级部门研发中心和销售中心上个月的用量
$gateway-ops 查看用户 zhangsan 上个月用量
$gateway-ops 导出当前模型价格表
$gateway-ops 预览报价表价格更新
$gateway-ops 预览 A 站同步到 B 站的价格变化
```
