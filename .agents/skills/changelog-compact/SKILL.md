# 精简本地定制清单

先读取适用 AGENTS.md、[项目配置](../../skill-project.md)的 `changelog` 和实际日志。只对明确的 `local-customizations` 按当前有效行为整理；普通 `release-history` 不按现状删除历史，润色也须保留版本事实。类型未知先澄清。

默认处理索引与关联详情，指定主题或编号时限制编辑范围。只要求预览就输出方案，明确要求精简则调查后直接编辑。保留用户改动，默认不暂存、不提交、不推送，不改业务代码、测试、技能或规范，不创建报告、归档或新功能编号。

## 核实

- 检查状态，完整读取索引和相关详情，按实际能力组织新增、调整、移除及改名记录。
- 以当前有效代码为准，兼顾相关暂存与工作区改动，检查入口、调用方、配置和历史。路径不存在先查搬迁、重命名或替代；不能仅凭未搜到、删除文件或标题含“移除”判断能力消失。
- 判断二开差异时固定实际上游来源、已集成基线与本地版本。可用 `git log --all -- <path>`、`git show <sha>:<path>`、`git diff <base> <local> -- <path>` 取证，不为整理而合并、覆盖工作区或改写历史。
- 证据不足保留并列为未核实。读取代码不是运行验证；仅文档整理做静态检查，其他验证遵循当前项目规则和任务授权。

## 合并与消除

共用文件或目录不能单独作为合并依据，按业务能力和实际行为判断。

| 情况 | 处理 |
| --- | --- |
| 本地新增后完全撤销，无有效差异和遗留影响 | 同时消除新增和撤销描述，整条失效才删整条 |
| 部分撤销 | 去掉对应部分，保留有效能力和约束 |
| 改名、重构或替代 | 写当前名称、入口和最终行为，保留必要兼容映射 |
| 本地移除上游能力 | 保留移除记录，仍是有效二开差异 |
| 撤销后仍有迁移、旧值转换、遗留字段或兼容接口 | 删除失效能力描述，保留当前升级和运行约束 |
| 已集成上游完整覆盖本地能力 | 行为、权限、默认值和兼容语义等价后才消除，仍有差异则保留 |
| 同一功能分散多条或多次追加 | 合并最终内容，不丢失角色、模式、限制与回退 |
| 纯上游同步、合并或冲突过程 | 从二开清单去除，不转存另一条二开记录 |

删除同义重复、中间尝试和无独立意义的微调，保留权限、默认值、配置、异常、计费、持久化与兼容约束。不能用“统一处理”“体验优化”替代具体规则。详情按能力组织，不强制套模板，不伪称语言或模式已全覆盖。

## 编号、日期与引用

- 保留原编号，不重排或复用空缺。合并保留代表主题的原编号，修复日志范围内引用；范围外引用在交付列出，不能静默留下断链。
- 文案整理不改成当天日期。合并用最终保留行为的可核实业务变更日期，未知保留并说明；索引与详情一致。
- 同步标题、正文、入口和文件清单，消除内容不留在详情中继续充当有效能力。迁移路径确认对应关系后才更新。
- 详情专属内容失效、无有效剩余且无其他引用时才删除；未被主索引链接不足以证明可删。共享详情只删对应部分，不增加墓碑或删除清单。

## 验证与交付

检查实际 diff、`git diff --check`、编号唯一性、表格与链接，确认删除详情无残留引用。简述整理主题、合并或消除记录、关键兼容约束与未核实事项。措辞压缩不能报告为已核实全部二开差异。
